# 常见错误解决指南

## 错误：Cannot GET /api/user/qyh10300/follow

### 问题原因

这个错误表示你使用了 **GET** 方法访问关注API，但关注API需要使用 **POST** 方法。

### 解决方案

#### 方法1：在 Postman 中使用 POST 方法

1. 打开 Postman
2. 创建新请求或选择 **"5. 关注用户"**
3. **重要**：确保方法选择为 **POST**（不是 GET）
4. URL：`http://localhost:3000/api/user/qyh10300/follow`
5. Headers：
   ```
   token: ztl10300
   Content-Type: application/json
   ```
6. 点击 **Send**

#### 方法2：在浏览器中使用 JavaScript

**注意**：浏览器地址栏默认使用 GET 方法，所以不能直接在地址栏访问。

在浏览器控制台（F12 → Console）中执行：

```javascript
fetch('http://localhost:3000/api/user/qyh10300/follow', {
  method: 'POST',  // ← 重要：必须是 POST
  headers: {
    'token': 'ztl10300',
    'Content-Type': 'application/json'
  }
})
.then(res => res.json())
.then(data => console.log('关注结果:', data))
.catch(err => console.error('错误:', err))
```

## 其他常见错误

### 错误：401 - 未提供认证令牌

**原因**：没有在 Headers 中添加 `token` 字段。

**解决**：在 Postman 的 Headers 中添加：
```
token: ztl10300
```

---

### 错误：404 - 目标用户不存在

**原因**：要关注的用户名不存在或拼写错误。

**解决**：
1. 检查用户名是否正确（`qyh10300`）
2. 可以先调用 `GET /api/user/qyh10300` 确认用户存在

---

### 错误：400 - 不能关注自己

**原因**：尝试关注自己。

**解决**：使用不同的用户名进行测试。

---

### 错误：500 - 服务器内部错误

**原因**：后端服务器可能未启动或数据库连接失败。

**解决**：
1. 检查后端服务器是否运行（`http://localhost:3000`）
2. 检查 MongoDB 数据库是否连接成功
3. 查看后端控制台的错误信息

---

## Postman 正确配置示例

### 关注用户请求配置

**方法**：`POST`（不是 GET！）

**URL**：
```
http://localhost:3000/api/user/qyh10300/follow
```

**Headers**：
```
Key: token
Value: ztl10300

Key: Content-Type
Value: application/json
```

**Body**：
- 不需要 Body（留空即可）

**预期响应**：
```json
{
  "code": 0,
  "message": "已关注用户 qyh10300",
  "isFollowing": true,
  "targetUser": {
    "_id": "...",
    "username": "qyh10300",
    "nickname": "..."
  }
}
```

## 快速检查清单

测试关注功能前，请确认：

- [ ] 后端服务器正在运行（`http://localhost:3000`）
- [ ] 使用 **POST** 方法（不是 GET）
- [ ] URL 正确：`/api/user/:username/follow`
- [ ] Headers 中有 `token` 字段
- [ ] `token` 的值是正确的用户名（`ztl10300`）
- [ ] 目标用户名存在（`qyh10300`）

---

## 测试步骤回顾

1. **设置 Postman Collection 变量**
   - `username`: `ztl10300`
   - `target_username`: `qyh10300`

2. **选择正确的请求**
   - 点击 **"5. 关注用户"**
   - **确认方法是 POST**（在 Postman 顶部的方法下拉菜单中）

3. **发送请求**
   - 点击 **Send**
   - 查看响应

4. **验证结果**
   - 调用 **"4. 获取个人主页"** 查看 `qyh10300` 的个人主页

   - 检查 `粉丝` 列表是否包含 `ztl10300`
