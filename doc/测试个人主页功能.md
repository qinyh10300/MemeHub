# 个人主页功能测试指南

## 测试目标
测试个人主页的四个标签页：
1. **我创作的模因** - 显示用户创建的模因
2. **我的模因币** - 显示用户的模因币（目前为空，待实现）
3. **我的收藏** - 显示用户收藏的模因
4. **粉丝** - 显示粉丝列表（目前为空，待实现）

## 测试步骤

### 前置条件
1. 确保后端服务器正在运行（`http://localhost:3000`）
2. 确保前端服务器正在运行
3. 已注册并登录一个账号

### 步骤1：创建模因（测试"我创作的模因"）

#### 方法A：使用前端界面
1. 登录后，点击右上角的"创建模因"按钮
2. 填写模因信息：
   - **标题（title）**：例如 "测试模因1"
   - **代号（ticker）**：例如 "TEST1"
   - **简介（description）**：例如 "这是我的第一个测试模因"
   - **上传图片**：选择一张图片文件
3. 点击创建按钮
4. 创建成功后，该模因会自动添加到"我创作的模因"列表中

#### 方法B：使用 Postman 或 curl
```bash
# 使用 curl 创建模因
curl -X POST http://localhost:3000/api/upload-meme \
  -H "token: 你的用户名" \
  -F "title=测试模因1" \
  -F "ticker=TEST1" \
  -F "description=这是我的第一个测试模因" \
  -F "file=@/path/to/your/image.jpg"
```

**注意**：`token` 字段目前使用用户名作为值（临时实现）

### 步骤2：收藏模因（测试"我的收藏"）

#### 方法A：使用前端界面
1. 在首页或其他用户的个人主页找到一些模因
2. 点击模因进入详情页
3. 点击收藏按钮（如果前端已实现）
4. 收藏成功后，该模因会出现在"我的收藏"列表中

#### 方法B：使用 Postman 或 curl
首先需要获取一个模因的ID（可以从首页列表或其他地方获取），然后：

```bash
# 收藏模因（需要模因ID）
curl -X POST http://localhost:3000/api/meme/模因ID/favorite \
  -H "token: 你的用户名" \
  -H "Content-Type: application/json"
```

**示例**：
```bash
# 假设模因ID是 507f1f77bcf86cd799439011
curl -X POST http://localhost:3000/api/meme/507f1f77bcf86cd799439011/favorite \
  -H "token: testuser123" \
  -H "Content-Type: application/json"
```

### 步骤3：查看个人主页

1. 登录后，点击右上角的"个人主页"按钮或左侧导航栏的"个人主页"
2. 页面会显示：
   - **我创作的模因**：显示你创建的所有模因
   - **我的收藏**：显示你收藏的所有模因
   - **我的模因币**：目前为空（功能待实现）
   - **粉丝**：目前为空（功能待实现）

### 步骤4：验证数据

- 每个模因显示：图片、名称、代号、描述

#### 检查"我的收藏"

- 每个模因显示：图片、名称、代号、描述

#### 检查"我的模因币"
- 目前应该显示为空数组（功能待实现）

#### 检查"粉丝"
- 目前应该显示为空数组（功能待实现）

## 常见问题

### Q: 为什么"我的模因币"和"粉丝"是空的？
A: 这两个功能目前还未实现，后端返回的是空数组。需要后续开发。

### Q: 如何获取模因ID？
A: 可以通过以下方式：
1. 创建模因后，API响应中会返回 `_id` 字段
2. 访问 `/api/meme-list` 获取模因列表
3. 在前端浏览模因时，URL中会包含模因ID（如 `/meme/507f1f77bcf86cd799439011`）

### Q: 为什么收藏后看不到？
A: 请确保：
1. 刷新个人主页页面
2. 检查API调用是否成功（查看浏览器控制台）
3. 确认使用的是正确的用户名作为token

### Q: 如何查看API返回的数据？
A: 打开浏览器开发者工具（F12），在Console标签中可以看到API请求和响应的日志。

## API 端点参考

- **创建模因**：`POST /api/upload-meme`
  - Headers: `token: 用户名`
  - Body: `title`, `ticker`, `description`, `file` (multipart/form-data)

- **收藏模因**：`POST /api/meme/:id/favorite`
  - Headers: `token: 用户名`

- **获取个人主页**：`GET /api/user/:username`
  - 返回用户的所有数据，包括创作的模因和收藏的模因
